# Bienvenidos al mundo de Pokémon. Ahora en Español.

- ENG: This translation is made with the main purpose of making this port reach to more people in the commmunity as the Pokémon Spanish Community is way too wide in many countries around the world.
It's understandable that many want to try this recompilation but the language barrier is a big obstacle they have to overcome. I hope this works as a help for those who struggle with English and just want to play. 
Plus, I'd like to add this project is too much for just a single person. Any help in this project is appreciated.

- ESP: Esta traducción se hace con el objetivo principal de hacer llegar este port a más personas de la comunidad ya que la Comunidad Hispana de Pokémon es muy amplia en varios países del mundo.
Es entendible que varios quieren probar esta recompilación pero la barrera del lenguaje es un obstaculo enorme que deben superar. Espero que esto sirva de ayuda para aquellos que tienen problemas con el inglés y solo quieren jugar. Además, me gustaría añadir que este proyecto es demasiado para una sola persona. Cualquier ayuda en este proyecto será agradecida.
